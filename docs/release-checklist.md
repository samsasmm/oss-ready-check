# Release Checklist

Use this checklist before publishing each release.

## Before Release

- Confirm the app opens locally
- Confirm checking items updates the score
- Confirm the Markdown report includes the repository name and score
- Update `CHANGELOG.md`
- Update the screenshot if the interface changed
- Review README instructions

## GitHub Release Notes Template

```md
## What's new

- Added the first browser-based OSS readiness checklist
- Added readiness scoring and practical suggestions
- Added copyable Markdown report
- Added beginner-friendly open source project documentation

## Who should use this

First-time GitHub maintainers preparing a small project for public release.

## Verification

- Opened the app locally
- Checked that score updates when items are selected
- Checked that the Markdown report updates correctly
```
