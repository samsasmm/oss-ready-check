# Roadmap

## v0.1.0 - Browser Checklist

- Static browser-based checklist
- Repository readiness score
- Practical suggestions for missing items
- Copyable Markdown report
- Basic documentation for GitHub beginners

## v0.2.0 - Better Templates

- Public GitHub repository URL scanner
- Automatic readiness scoring
- Detection evidence for each scanned signal
- README section suggestions
- Issue template suggestions
- Release checklist
- Beginner-friendly examples for common project types
- Project-type checklist presets
- Improved Markdown report formatting
- Beginner guide for publishing a GitHub Pages demo

## v0.3.0 - Repository URL Review

- Deeper README quality scoring
- More project-type specific recommendations
- Better rate-limit and private-repository messaging

## Later Ideas

- Multi-language interface
- GitHub Pages demo site
- Project-type presets for tools, websites, libraries, and documentation projects
- Exportable project health badge or report
