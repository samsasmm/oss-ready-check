# Contributing

Thank you for considering a contribution to OSS Ready Check.

This project is intentionally small and beginner-friendly. The best contributions are practical improvements that help new maintainers prepare better open source repositories.

## Good First Contributions

- Improve checklist wording
- Add examples for beginner repositories
- Improve documentation clarity
- Report confusing user experience
- Suggest missing readiness checks

## Contribution Principles

- Keep the tool simple enough for beginners
- Prefer clear suggestions over abstract scores
- Explain open source habits in plain language
- Avoid adding heavy dependencies without a strong reason

## Development Notes

The first version is planned as a static web app. It should be possible to open and test locally without a complex setup.

## Reporting Issues

When reporting an issue, please include:

- What you expected to happen
- What actually happened
- Your browser and operating system, if relevant
- A screenshot if the problem is visual
