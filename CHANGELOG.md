# Changelog

All notable changes to this project will be documented in this file.

This project follows a simple versioning style suitable for small open source tools.

## 0.2.0 - 2026-06-07

Added:

- Public GitHub repository URL scanner
- Automatic repository readiness checks through GitHub's public API
- Detection evidence for README, license, description, usage instructions, demo links, issue templates, contribution guide, roadmap, changelog, workflows, and recent activity
- Manual fallback check for project scope judgment
- Updated screenshot and README for the automatic scanner

## 0.1.0 - 2026-06-07

Added:

- First public browser-based checklist
- Readiness scoring
- Copyable Markdown report
- Beginner-focused project documentation
- GitHub issue templates and pull request template
- GitHub Pages deployment workflow
